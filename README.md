### 🌿 Tea‑House

A simple yet elegant static website built with **HTML**, **CSS**, and **Tailwind CSS**.

## Demo
https://sadia-chowdhury.github.io/Tea-House/

**Key Features:**

* Fully responsive layout showcasing a tea-themed design.
* Clean structure using semantic HTML.
* Styled efficiently using utility-first classes from Tailwind CSS.
* Ideal for portfolio showcases, landing pages, or design exercises.

**Tech Stack:**

* **HTML5** for semantic markup
* **Tailwind CSS** for modern, utility-first styling
* No external JS dependencies

**Usage:**

1. Clone the repository.
2. Run `npm install tailwindcss` (if not already installed) and generate CSS with Tailwind build process.
3. Open `index.html` in your browser to explore.
